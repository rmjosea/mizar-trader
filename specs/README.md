# Product specifications

One spec per backlog functional block, stored as
`specs/<BLOCK-ID>-<slug>/spec.md` with ID `SPEC-<BLOCK-ID>`, written with the
`spec` skill. States: `draft` (being written), `approved` (the user confirmed
it), `done` (every acceptance criterion has merged evidence).
