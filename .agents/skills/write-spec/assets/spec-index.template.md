|---|---|---|---|

## Status definitions

- `draft`: being authored or awaiting product approval.
- `approved`: behavior and acceptance criteria are confirmed.
- `planned`: an approved technical plan covers the specification; optional when
  no durable plan adds value.
- `implemented`: implementation is complete but not yet verified by review
  evidence.
- `verified`: review evidence confirms the acceptance criteria.
